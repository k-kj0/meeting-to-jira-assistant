FAQ

Questions? Answered.

Does it work with Zoom or Google Meet transcripts? +
Yes — paste any plain text transcript. Zoom auto-transcripts, Google Meet captions, Otter.ai exports, or raw meeting notes all work. The NLP pipeline handles messy punctuation and speaker labels.
How does it filter out noise from real action items? +
It looks for commitment signals — future tense verbs, ownership language, and deadline markers. Vague suggestions like "maybe we should" or "someone could look into" are ignored before tickets are ever created.
Is my meeting transcript data stored? +
Transcripts are processed in real-time and immediately discarded. No meeting content is retained after the API returns your tickets.
What Jira plan do I need? +
Jira Cloud free tier and above. You'll need an Atlassian API token — setup takes under 2 minutes and the token is stored locally.
Can it handle large transcripts with many speakers? +
Yes — a 90-minute all-hands transcript typically produces 15-25 tickets, each correctly attributed. The pipeline scales linearly with transcript length.
