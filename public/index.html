Process

Two steps.
Real tickets.

From messy transcript to a live GitHub Issue.

01

Paste your transcript

Zoom captions, Meet transcripts, raw notes — anything works.

02

AI extracts commitments

A free OpenRouter-hosted model reads the text and returns only real, owned commitments — vague suggestions are dropped.

03

Click to create the ticket

Each extracted item gets a "Create ticket" button. One click makes a real, clickable GitHub Issue.

Under the hood

One AI call.
One API call.

No keyword tricks. A real model reads the transcript; a real API creates the ticket.

🧠

OpenRouter free-tier extraction

The transcript is sent to a free open-weight model via OpenRouter. It returns structured JSON — task, assignee, deadline.

🎫

GitHub Issues as the board

Tickets are created directly as GitHub Issues in a repo you choose — no OAuth dance, no credit card.

✅

Review before creating

Extracted items are shown first. Nothing is created until you click the button for that specific item.

🔒

Your keys, your data

API keys live in Vercel's environment variables (or your local .env). Nothing is stored beyond a single request.
